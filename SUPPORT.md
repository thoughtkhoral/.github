# Support

Use the issue form in the repository that owns the behavior:

- installation, Compose, Kubernetes, or smoke-test problems: `thought-khoral-platform`;
- protocol, schema, or fixture questions: `thought-khoral-contracts`;
- room authentication, events, persistence, or authorization: `thought-khoral-room-gateway`;
- browser behavior or UI tests: `thought-khoral-workspace-ui`;
- specification, roadmap, or cross-project questions: `thought-khoral`.

Include the commit or release, environment, commands run, expected behavior,
observed behavior, and relevant logs with credentials and room content removed.
